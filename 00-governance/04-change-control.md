# Change Control

- **Class A — Editorial:** spelling, formatting, links; no meaning change.
- **Class B — Clarification:** explains existing canon without changing meaning.
- **Class C — Canon Addition:** adds previously undefined truth.
- **Class D — Canon Modification:** changes approved truth.
- **Class E — Foundation/Governance Change:** changes governance, storyworld laws, core continuity architecture, major chronology, or another foundation.

A scene-writing task does not grant permission for Class C-E changes outside the scene's owned scope.

Class D/E changes require:
1. an approved Decision Record;
2. impact review of affected Canon IDs;
3. migration of every affected Source-of-Truth record;
4. validation and review before promotion.

An approved decision with incomplete migration is `BLOCKED`, not current canon.

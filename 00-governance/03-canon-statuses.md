# Canon Statuses

Valid statuses:

- `LOCKED_CANON` — foundational approved truth; deliberate change only.
- `CANON` — approved current truth.
- `WORKING` — active development; not approved truth.
- `PROPOSAL` — idea awaiting development/approval.
- `SUPERSEDED` — former canon retained for provenance.
- `REJECTED` — explicitly not canon.

Normal promotion: `PROPOSAL → WORKING → CANON → LOCKED_CANON`

Not every object should become locked. `SUPERSEDED` and `REJECTED` IDs remain permanently reserved.

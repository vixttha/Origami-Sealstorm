# Governance

This directory is the constitution of the storyworld repository. It governs how canon is created, scoped, changed, reviewed, superseded, researched, and consumed by humans and AI.

## Governing principle

**one fact → one owner → one Canon ID → explicit status → controlled changes → evidence → review → promotion**

# Schemas

Machine-readable contracts for the reusable framework.

- `storyworld.schema.json` validates `STORYWORLD.yaml`.
- `canon-registry.schema.json` validates the registry envelope and entry shape.
- Cross-file rules require the cloud review checklist; Python validation is available only in a separate optional developer package, not v1.0.

Schemas use JSON Schema Draft 2020-12.

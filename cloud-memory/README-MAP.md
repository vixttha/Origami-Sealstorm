# Quick Cloud Memory Map

**Canonical**: `CANON-REGISTRY.yaml` resolves permanent IDs to Source-of-Truth owners inside `01-storyworld-core/` through `10-visual-language/`. It is the lookup index, not a second lore bible.

**Decisions**: `00-governance/decisions/` records approved change authorization; updated registered owners remain factual authority.

**Archives**: `99-archive/` and Git history preserve retired and superseded material, never default current truth.

**Working story memory**: `06-stories/`, `04-characters/`, `05-events/` provide story authoring context. Optional interactive-narrative game tooling is maintained separately and does not ship in the public v1.0 writer core.

**Temporary context**: `cloud-memory/CONTEXT-PACKET-TEMPLATE.md` reconstructs task-specific context from SHA-pinned owners. This is an index and guide, not an automated persistent vector database.

**Cloud-only audits**: `docs/CLOUD-REVIEW-CHECKLIST.md` describes exact-SHA static review and evidence levels; no runner is required.

**Priority**: latest approved Source-of-Truth records + recorded scope over old AI/chat summaries, search indexes, prompt caches or unreconciled memory.

# Start Here

## This is a ChatGPT.com writing template, not an application

Start with [ChatGPT Chat-First — Free, No-Computer Storyworld Workflow](docs/CHATGPT-CHAT-FIRST-WORKFLOW.md), then `SETUP.md`. You can create and maintain a storyworld using ChatGPT chat plus GitHub web editing from a phone. A GitHub connector, local Python, terminal, browser inspector or paid plan is **not a requirement**. If an account lacks ChatGPT-GitHub read access, paste only the relevant GitHub files into chat; a pasted file is not independent SHA verification.

## Before canon-sensitive work

Read in this order:

1. `STORYWORLD.yaml`
2. `CURRENT-STATE.md`
3. `CANON-REGISTRY.yaml`
4. `00-governance/README.md`
5. `00-governance/13-llm-context-protocol.md`
6. only the registered Source-of-Truth owners and dependencies relevant to the task

## Core rule

Never infer canon from file age, prose confidence, filename, chat history, or the fact that a file exists.

Authority comes from governance, the Canon Registry, Source-of-Truth ownership, explicit status, and approved change control.

Do not use `99-archive/` as current canon.

## Cloud-only recall and runnerless review

Use `cloud-memory/CLOUD-RECALL-PROTOCOL.md` to retrieve Source-of-Truth owners through a connected GitHub app **when available**, or follow the manual copy/paste path in `docs/CHATGPT-CHAT-FIRST-WORKFLOW.md`. For static review without runners see `docs/CLOUD-REVIEW-CHECKLIST.md`. Standalone browser modules, scripts, CLI exporters and browser/OS execution tests are optional maintainer tools and are not included in the public writer-first v1.0 release. Never label unexecuted tests as PASS. No external governance system, local installation, hosted CI or always-on service is required for core authoring.
